# 共通デザイントークン

自社アプリ(買取案件管理・賃貸管理アプリ、今後増える分も含む)で共有する、色・角丸・文字サイズ・間隔などの「唯一の正」となる値です。

**新しい画面・新しいシステムを作る前に、まず [UIUXルール.md](UIUXルール.md) を読んでください。** なぜこの値・この構造にするのかの考え方をまとめています。このJSON(②デザインシステム)は、そのルールを数値に落とし込んだものです。

## 使い方

**値を変えたい時**: `design-tokens.json` だけを編集してください。他のファイルは直接編集しないでください。

**買取案件管理(anken, PHP版・停止予定)に反映する**(anken-reactは対象外。下記参照):
```
node "共通デザイントークン/sync-to-anken.mjs"
```
anken の `index.html` の `:root{...}` のうち、この JSON に載っている変数だけを更新します。anken 独自の色(買取/仲介バッジなど、JSONに存在しない変数)はそのまま残ります。実行後は `git diff` で変更点を確認し、問題なければコミットしてください。

**注(2026-09-21)**: 買取案件管理は anken-react に移行済みです。anken-react は rent-management-app と同じく `tailwind.config.js` がこの JSON を直接読み込むため、このコマンドの実行は不要です。上記は旧PHP版anken(停止予定・完全廃止までの保守用)にのみ必要です。

**賃貸管理アプリ(rent-management-app)に反映する**: 何もしなくて大丈夫です。`tailwind.config.js` が起動のたびにこの JSON を直接読み込むので、JSON を編集して保存するだけで自動的に反映されます(開発サーバーの再起動は必要)。

## rent-management-app 側の使い方

既存の意味のある名前(`bg-info`, `text-danger` など)はそのまま使えます。値は共有JSONから自動的に取られるので、anken側と自然に一致します。

ankenの実測値にピクセル単位で正確に合わせたい部品(ログイン画面のように「そっくりに作ったのに微妙にズレる」を防ぎたい場合)は、追加された以下のクラスを使ってください。

| 用途 | クラス例 | 対応するanken変数 |
|---|---|---|
| 角丸 | `rounded-r8`, `rounded-r20` | `var(--r8)`, `var(--r20)` |
| 文字サイズ | `text-f13`, `text-f26` | `var(--f13)`, `var(--f26)` |
| 間隔 | `p-sp9`, `gap-sp12`, `px-sp14` | `var(--sp9)`, `var(--sp12)`, `var(--sp14)` |
| 枠線太さ | `border-bw0`(0.5px) | `var(--bw0)` |
| アニメーション速度 | `duration-dur2` | `var(--dur2)` |
| z-index | `z-zmodal`, `z-ztoast` | `var(--zmodal)`, `var(--ztoast)` |

これらは既存のTailwind標準クラス(`rounded-lg`, `text-sm`, `p-4`など)を置き換えるものではなく、**「anken と寸分違わず揃えたい」時だけ使う追加の選択肢**です。
